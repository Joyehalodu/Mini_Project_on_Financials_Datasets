# Mini_Project_on_Financials_Datasets
## Project Overview

* This project focuses on analyzing business sales performance using Microsoft Power BI. The goal was to transform raw sales data into meaningful insights through interactive dashboards and visualizations.
* Dataset Description
The dataset used for this project contains transactional sales data with the following key fields:
* Sales
* Profit
* COGS
* Year
* Discounts
* Date
* Month Number
* Discount Band
* Month Name
* Gross Sales
* Sale Price
* Manufacturing Price
* Units Sold
* Product
* Segment
* Country

## Objectives
* The main objectives of this project were to:
* Analyze overall sales performance
* Identify top-performing products and regions
* Build an interactive dashboard for stakeholders
* How to increase the sales of products which were not being sold very well

## Key Insights
* Certain regions consistently outperform others in total sales
* A small number of products contribute to a large portion of revenue
* Sales show seasonal trends with noticeable peak periods
* Profit margins vary significantly across product categories

## Conclusion
This project demonstrates how Microsoft Power BI can be used to convert raw data into actionable insights. The dashboard enables stakeholders to monitor performance and make informed business decisions effectively.
