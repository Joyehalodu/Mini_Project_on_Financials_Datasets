# Mini_Project_on_Financials_Datasets
## Project Overview

* This project focuses on analyzing business sales performance using Microsoft Power BI. The goal was to transform raw sales data into meaningful insights through interactive dashboards and visualizations.
* Dataset Description
The dataset used for this project contains transactional sales data with the following key fields:
* Sales
* Profit
* COGS
* Year
* Discounts
* Date
* Month Number
* Discount Band
* Month Name
* Gross Sales
* Sale Price
* Manufacturing Price
* Units Sold
* Product
* Segment
* Country

## Objectives
* The main objectives of this project were to:
* Analyze overall sales performance
* Identify top-performing products and regions
* Understand customer purchasing behavior
* Track profit trends over time
* Build an interactive dashboard for stakeholders
